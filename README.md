# Automated Checkers on UR5e – Startup Procedure

**Important:** Launch each component in the exact order shown below.

---

## Terminal 1 — RealSense Camera

Launch the Intel RealSense D435 camera.

```bash
ros2 launch realsense2_camera rs_launch.py
```

---

## Terminal 2 — UR5e Driver

Launch the UR5e driver.

> **Note:** Ensure the robot IP matches the address shown on the teach pendant.

```bash
ros2 launch ur_robot_driver ur_control.launch.py \
  ur_type:=ur5e \
  robot_ip:=192.168.56.101
```

---

## Terminal 3 — MoveIt

Launch MoveIt and RViz.

```bash
ros2 launch ur_moveit_config ur_moveit.launch.py \
  ur_type:=ur5e \
  launch_rviz:=true
```

---

## Terminal 4 — Robotiq Hand-E Driver

Launch the gripper driver.

> **Note:** Verify the USB serial port before launching.

```bash
ros2 launch robotiq_hande_driver gripper_controller_preview.launch.py \
  use_fake_hardware:=false \
  tty_port:=/dev/ttyUSB0
```

---

## Terminal 5 — Gripper Command Node

Provides open/close control for the gripper.

```bash
ros2 run ur5e_manoeuvring gripper_command_node \
  --ros-args \
  -p arm_model:=ur5e \
  -p open_position:=0.025 \
  -p closed_position:=0.013
```

---

## Optional — Simulated Checkerboard Publisher

Publishes a virtual checkerboard for testing.

```bash
ros2 run ur5e_manoeuvring chessboard_marker_node \
  --ros-args \
  -p origin_x:=-0.075 \
  -p origin_y:=0.20 \
  -p origin_z:=0.00 \
  -p square_size:=0.05 \
  -p rotation_steps:=2
```

---

## Terminal 6 — Checkerboard Pose Node

Converts board indices into robot poses.

> ⚠️ **Warning:** The robot will move to the HOME position immediately after this node starts.

```bash
ros2 run ur5e_manoeuvring checkerboard_pose_node \
  --ros-args \
  -p origin_x:=-0.075 \
  -p origin_y:=0.20 \
  -p origin_z:=0.00 \
  -p square_size:=0.05 \
  -p rotation_steps:=2 \
  -p hover_height:=0.25 \
  -p descent_height:=0.08 \
  -p velocity_scaling:=0.15 \
  -p acceleration_scaling:=0.12 \
  -p lift_height:=0.08
```

---

## Terminal 7 — Workspace Bounding Box

Creates the MoveIt workspace constraints.

```bash
ros2 run ur5e_manoeuvring bounding_box_node \
  --ros-args \
  -p board_x:=-0.075 \
  -p board_y:=0.20 \
  -p board_z:=0.0 \
  -p front_dist:=0.50 \
  -p back_dist:=0.50 \
  -p right_dist:=1.00 \
  -p left_dist:=0.23 \
  -p ceiling_height:=0.90
```

---

## Terminal 8 — Robot Controller

Executes robot move sequences generated by the game controller.

```bash
ros2 run game_state_machine robot_controller
```

---

## Terminal 9 — Game Controller

Runs the game state machine and AI.

```bash
ros2 run game_state_machine game_controller
```

---

## Terminal 10 — Perception Node

Runs checker detection and board-state estimation.

> **Note:** Detection parameters are loaded from the YAML configuration file.

```bash
ros2 run perception checkers_perception \
  --ros-args \
  --params-file src/perception/config/checkers_perception.yaml
```

---

# Startup Order Summary

1. RealSense Camera
2. UR5e Driver
3. MoveIt
4. Robotiq Hand-E Driver
5. Gripper Command Node
6. Checkerboard Pose Node
7. Bounding Box Node
8. Robot Controller
9. Game Controller
10. Perception Node

---

# Pre-Run Checklist

- [ ] UR5e powered on and released from protective stop
- [ ] Robot IP address verified
- [ ] Gripper USB port verified (`/dev/ttyUSB0`)
- [ ] Checkerboard positioned correctly
- [ ] Camera has unobstructed view of board
- [ ] Robot moves to HOME after launching pose node
- [ ] Perception node publishes valid board states
